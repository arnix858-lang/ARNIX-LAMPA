# ARNIX LAMPA

Цель репозитория — полноценная сборка веб-приложения Lampa из исходного проекта, а не одиночная HTML-страница.

## Импорт полного проекта и первая публикация

1. Откройте вкладку **Actions**: https://github.com/arnix858-lang/ARNIX-LAMPA/actions
2. Выберите workflow **Build and publish full Lampa source**.
3. Нажмите **Run workflow** → **Run workflow**.
4. Дождитесь завершения всех шагов.

При ручном запуске workflow автоматически клонирует полный публичный исходный проект https://github.com/yumata/lampa-source, переносит его исходные каталоги в этот репозиторий, устанавливает зависимости, собирает веб-версию командой `gulp pack_github` и публикует результат в GitHub Pages.

## Состав исходного проекта после импорта

Будут импортированы исходные каталоги и файлы проекта: `src/`, `public/`, `plugins/`, `index/`, `gulpfile.js`, `package.json`, документация и лицензия. Сборка сайта создаётся в `build/github/lampa/`.
