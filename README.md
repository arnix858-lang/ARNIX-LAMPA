# ARNIX LAMPA

Русскоязычная адаптивная веб-оболочка в стиле Lampa для телефонов, планшетов и ПК.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages:
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Source: GitHub Actions.
3. Если GitHub предложит подтвердить настройки, подтвердите их. Workflow уже добавлен в `.github/workflows/pages.yml`.

После публикации сайт будет доступен по адресу:
https://arnix858-lang.github.io/ARNIX-LAMPA/

## Текущий статус
Это стартовая веб-версия ARNIX LAMPA: адаптивный интерфейс, поиск по демонстрационным карточкам, фильтры жанров, окно описания и избранное в браузере. Демонстрационные данные не являются реальным каталогом, а воспроизведение фильмов пока не подключено.

## Авторство и лицензия
Оригинальный проект Lampa: https://github.com/yumata/lampa-source (GPL-2.0).
Этот репозиторий ARNIX LAMPA пока содержит самостоятельную стартовую веб-оболочку, а не копию исходного кода Lampa. Если в дальнейшем будут перенесены компоненты GPL-2.0, соответствующие исходники и уведомления о лицензии будут сохранены.
